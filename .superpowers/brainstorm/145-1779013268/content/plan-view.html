Step 3: How should the "Plan" screen be organized?

This screen merges three current pieces: skills to learn (Tab 2), soft skills (Tab 2 bottom), and in-demand skills for the chosen career (Tab 3). It's the densest screen — pick the layout.

A. Stacked Sections

One long scroll: Skills to learn first (primary), then Soft skills, then What's in demand. Simple, no sub-navigation. Easy to skim top-to-bottom but can feel long.

B. Two-Column + Soft Skills Below

Top row: Skills to learn (left, wider) + In-demand (right, sidebar context). Soft skills as a band below. Cross-references at a glance — user can see "this skill I should learn IS in demand."

C. Sub-Tabs Within Plan

Plan screen has 3 sub-tabs: Learn / Soft Skills / Market. Compact, single section visible at a time. Cleanest but hides context (user has to click to discover soft skills + demand exist).
